###Sobre o projeto

O sistema permite registrar e visualizar notas de alunos, facilitando a comparação do desempenho acadêmico. A aplicação realiza cálculos automáticos de média e organiza os resultados por matéria, tornando a análise do rendimento escolar mais simples e intuitiva.

---
##Funcionalidades

Cadastro e visualização de notas dos alunos.

Comparação de notas entre diferentes alunos.

Cálculo automático da média das notas.

Identificação das matérias relacionadas às notas.

Organização dos resultados para facilitar a análise do desempenho acadêmico.

---

##Tecnologias utilizadas

React: biblioteca utilizada para a construção da interface.

Vite: ferramenta de desenvolvimento e compilação do projeto.

JavaScript: linguagem utilizada na implementação da lógica.

CSS: estilização e organização visual da aplicação.

HTML5: estruturação dos elementos da interface.
